# Agent Roster v1

The 13-agent organization is now represented as a governed manifest.

The manifest is metadata and authority definition; it is not permission by itself.

Permission remains:
Agent -> Capability -> Policy -> Approval -> Application Command.

Implemented executable agents:
- MKT-CMO-001
- MKT-STR-001

The remaining agents are registered as organizational authority/capability definitions first. They are deliberately not implemented as fake autonomous bots. Each will receive an executable workflow only when its authoritative objects, commands, policy rules, tools, and tests are defined.

This prevents the system from becoming 13 disconnected chatbots.
