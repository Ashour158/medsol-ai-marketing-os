# T1 editorial calendar and advisory conflict optimizer

Derives the calendar exclusively from existing exact creative approval schedules and linked CampaignPublication state; no additional scheduling or approval owner. Tenant manager loads bounded brand-scoped calendar for up to 31 days, with current version, reviewed rights, approved policy, exact scope digest and expiration checks. Refuse more than 200 active candidates rather than propose from an incomplete schedule. Detect same-channel same-destination collisions across the window boundary using operator-supplied minimum spacing, exclude stale/held/cancelled scopes. Each suggested later slot is independent, not a globally optimized plan or engagement forecast; changing it requires a fresh exact human approval.
