# T1 E22 — durable synthetic experiment assignments and recorded evidence

Reuse MarketingPerformanceService, MarketingConversionForm, MarketingConversionSubmission, synthetic consent and the canonical Approval ledger. A fixture-scoped immutable plan binds two different independently approved same-campaign form digests, the current campaign revision and active brand, 4–100 distinct eligible synthetic contacts and original consent-event IDs. Deterministic hash-ordered alternating assignment creates balanced fixed groups. Approval is independent and revalidates exact form/campaign/consent and absence of pre-existing submissions. SQL constrains the plan to one fixture key, protects immutable scope and decision, and checks same-tenant form relations. Only internal authenticated proposal and read routes are available.

The read-only report uses actual existing persisted synthetic submissions within the window from independent approval to expiry. Opposite-form crossovers and changed-consent contacts are excluded from successful counts, retained in assigned denominators and explicitly flagged as contamination. Historical results are not current consent authorization. No delivery, browser traffic, exposure, assignment enforcement on public traffic, real contact, actual lead, causal lift or experiment efficacy is claimed. Separate experiments must not be treated as independent exposure evidence. The operator controls mock submissions through the existing form workflow. Unit and PostgreSQL tests cover deterministic assignment, scope isolation, independent approval, changed consent, stale/pre-existing evidence, crossover and no effect. NOT_CERTIFIED. Real randomized exposure, statistical inference and release authorization remain pending.
