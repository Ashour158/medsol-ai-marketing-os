# T1 — durable synthetic CRM connector protocol

Extends the existing MarketingConversionSubmission ledger and SyntheticConversionService. No new CRM, contact owner, provider registry or credentials. Ten bounded provider-neutral mock scenarios execute only after current independent exact form approval, synthetic same-brand contact, explicit mock CRM purpose and current synthetic opt-in/no suppression. Deterministic request scope binds tenant, brand, campaign, form, contact, consent event and immutable submission digest. In-process acknowledgement, exact readback, callback deduplication and failure classification are preserved as immutable protocol evidence. Ambiguous, mismatched or malformed receipts never become accepted or authorize retry. SQL enforces no actual CRM requests, leads, remote receipts or external effects, and requires protocol evidence for new submissions; historic rows remain valid. UI exposes the fixed scenarios and persisted results. Unit and real PostgreSQL tests included. No live connector or hosted public form; provider-specific integration/CRM authority remain release gates. NOT_CERTIFIED.
