# Master Blueprint v2.2 — Native Creative & Motion Studio amendment
Date: 2026-11-26. Extends v2.1, not a replacement. Approved scope direction: feature inspiration only from Remotion, OpenMotion and other references; no copied code, assets, templates, guides, proprietary APIs or paid runtime dependency. Original implementation; any future dependency requires license review for commercial multi-tenant SaaS, SBOM and approval. No real provider accounts or external effects in this phase.

## Reuse and ownership
E11/E14/E32/WF06/WF19 retain Creative & DAM ownership, CreativeAssetRevision, CreativeAssetService and existing offline-layered-design renderer. Preserve 36 engines / 41 workflows and 13 canonical agents. Use existing creative agent skills rather than creating shadow identities. Existing campaign, approval, workflow, model gateway, knowledge, learning and audit owners retain authority. Existing 2–4 scene / 24-second offline storyboard, SVG and unverified browser WebM remain backward compatible. Never silently alter immutable source digests. No new release path bypassing maker-checker.

- M01 timeline frame addressing, deterministic scene boundaries and timebase; first bounded helper and tests.
- M02 versioned composition schema: multitrack layers, transforms, keyframes, transitions, easing, safe typography, shapes, motion graphics, editable source and undo/redo; original primitives only.
- M03 native editing UI: scrub, trim, reorder, preview, timeline tracks, scene editor, annotations, keyboard accessibility and revision conflict handling.
- M04 brand motion DNA: approved colors/fonts/logos, reusable original templates, localized RTL text and brand/claim validation.
- M05 AI brief-to-script/storyboard, creative direction, prompt-to-composition, governed reference analysis (authorized media only; no copying protected expression), motion design skills and approval; use existing provider gateway and simulated responses.
- M06 media/audio: approved local assets, captions, subtitles, voiceover via mock gateway, audio tracks, mixing/sync, rights, accessibility; later optional approved generative media providers.
- M07 deterministic frame rendering and isolated bounded render workers, job progress, cancellation, retries, quotas, idempotency, exact source-to-byte lineage, independent decode verification, codec/license review; export MP4/WebM only after verified support.
- M08 multiformat variants: landscape, square, portrait; responsive safe zones, batch rendering, language variants, product/data-to-video, personalized videos with consent and data minimization.
- M09 campaign integration: ads/reels/product demos, A/B variants, independent creative QA, approved claims, exact revision review, simulated delivery, analytics and learning from approved evidence.
- M10 advanced effects: optional 3D, background removal, color grading, editable export; no claim of support until implementation and tests.
- M11 enterprise controls: tenant isolation, authorization, asset rights/expiry, resource budgets, sandbox no network or arbitrary user code, media scanning, audit and immutable revision provenance.

## Delivery gates
A: timeline primitives and compatibility tests. B: versioned composition + editor + deterministic preview. C: sandbox render/encoded verification and audio. D: agentic planning, brand templates, variants and campaign workflow. E: full simulated journey, independent tenant/security tests, acceptance evidence and release gates. Each gate requires tests and owner reconciliation; no milestone closed on documentation alone. Keep prior Tranche 1 acceptance separate; no regression or reclassification of unverified capabilities. Production remains blocked pending independent acceptance and licensing/security review.

## Acceptance
Frame boundaries, invalid input, deterministic output and immutable legacy digests; cross-tenant asset denial; exact revision approval invalidation; independent media verification; bounded jobs and recovery; no external calls; full brief-to-render-to-review-to-simulated-delivery journey; RTL and accessible UI; audited cost and rights; independent QA. Feature ideas are references only, not imported implementation.
