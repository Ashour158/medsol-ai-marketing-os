# Phase 6B — Approved specialist batch dispatch

Extends #185 with an ordered dispatch command for one to four already independently approved decision-mode specialist rehearsals. Preflight validates exact scope, owner, tenant, independent approvals and distinct specialist identities before dispatch. Each step invokes the canonical AgentService execution path, rechecking current eligibility and reviewer authority for new executions. Stops on the first blocked or error result; remaining steps are NOT_DISPATCHED. Completed steps are committed individually, not rolled back; the operator can inspect authoritative AgentExecution records and resume explicitly using their immutable approval IDs. Historical receipts are replayed without another execution. No autonomous approval, automatic retry, shared source content, provider calls or permission expansion. Studio exposes batch references and per-stage status. Unit and signed real-stack tests cover preflight, dispatch, halted stages, replay and revoked upstream dependency. Exact-head CI required. This is operator-triggered ordered dispatch, not dynamic assignment, autonomous delegation or a durable workflow scheduler. #185 must pass before merging this candidate.
