# T1 — internal community SLA escalation

Adds priority deadlines to existing SocialCommunityCase: urgent 1h, high 4h, normal 24h, low 72h. These are conservative internal defaults, not customer-contract SLAs. The existing worker optionally scans due cases when MARKETING_BRAIN_WORKER_ENABLED and MARKETING_CRISIS_SLA_WORKER_ENABLED are both true. Internal queue marker and SYSTEM audit only; no email, external notification, automatic reply, provider call or professional credential claim. Serializable CAS and trigger enforce one escalation per case cycle; an overdue marker never changes the pinned specialist review round. Reopening resets the deadline and marker. Legacy cases without a deadline remain historical until reopened. Real database tests cover flags, concurrency, independent review after escalation, and reopening. NOT_CERTIFIED.
