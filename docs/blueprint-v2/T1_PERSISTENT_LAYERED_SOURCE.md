# T1 — Persistent editable design source and rendition lineage

Extends the canonical CreativeAsset and CreativeAssetRevision owner; no new DAM, rendering service or table. The next revision of the same active offline asset stores a bounded structured title/body/accent/layout source and the exact source/rendition SHA-256 digests. Parent is a same-tenant same-asset immediately prior offline revision, enforced by FK and trigger. The structured source deterministically renders a safe layered SVG; no remote URLs, raw SVG, arbitrary scripts, binary media or external font assets are accepted. This is a new editable layout, not a reconstruction of the parent PNG.

Explicit revision CAS, command-receipt replay, immutable source lineage and audit history. Previous exact approval becomes stale; no inherited rights or media verification. New layered-only revisions cannot request/receive a creative release approval until a separately verified rendition is engineered. Preview regenerates and verifies both digests, fails closed if inconsistent, and exposes a current-version guarded SVG download. Operator UI integrated into the existing campaign workspace, clears stale selections on save. Unit, real PostgreSQL and existing T4A browser acceptance extensions are required to pass CI. No external design provider, actual media-rights certification, multimedia renderer or production acceptance. NOT_CERTIFIED.
